## Install this requirements before installing:
niri

waybar (optional if you will have a noctalia)

wofi

awww (optional if you will have a noctalia)

fastfetch (optional)

kitty

noctalia (optional if you will have a waybar)

## How to download and install:
Enter this command in your ~ home folder for better work
```bash
git clone https://github.com/anoplaymc/niri-dotfiles.git && cd niri-dotfiles && chmod +x install.sh && ./install.sh && cd ~
```

## If installing finishes sucsessfuly:
This is an optional command to delete files and scripts needed to install dotfiles
```bash
cd ~ && rm -rf ~/niri-dotfiles
```
